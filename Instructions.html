GST Returns Downloader

User Guide & Instructions for automated batch downloading of GSTR-1, 2A, 2B, and 3B returns directly from the official GST Portal.

🚀 Step-by-Step Guide 🔒 Privacy & Security
📑

How to Download Returns

Automated batch retrieval directly from the official GST portal
Automation
  • Enter Portal Credentials
    Enter your official GST Portal Username and Password in the input fields.
  • Select Financial Year & Months
    Choose your target Financial Year (e.g., 2026-27) and check the months you want to download. Supports arbitrary individual months or full quarters.
  • Select Return Forms
    Check the return forms you need: GSTR-1 (PDF summary), GSTR-2A (Excel), GSTR-2B (Excel), and/or GSTR-3B (PDF).
  • Start Downloader & Solve CAPTCHA
    Click "Start Downloader". An automated browser session initializes, enters your credentials, and pauses to let you enter the visual CAPTCHA. Once logged in, the downloader navigates through all selected months automatically in the background.
⚡
Background Multi-Tasking: Once the initial CAPTCHA is solved, the downloader runs quietly in the background, updating progress in real time while you switch to other tabs or modules.
🔒

Security & Credential Privacy

Your portal credentials belong strictly to you
Volatile Memory

🔑 Volatile Session Memory

Your GST portal password is kept strictly in volatile memory during the active session. It is never logged, stored in plain text, or written to disk.

🛡️ Direct Portal Connection

Browser automation communicates directly between your PC and services.gst.gov.in. Zero intermediaries, proxies, or remote servers.

📁 Local Downloads

All downloaded return files are placed directly into your local destination directory with zero cloud synchronization.
